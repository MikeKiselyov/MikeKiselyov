## What I'm building

      <h3><a href="https://mikekiselyov.github.io/bearcorder/">Bearcorder</a></h3>
      A macOS menu bar app that always keeps the last minutes of your screen, so whatever you just saw is already recorded. Screenshots and clips with markup, bug reports, layout checks and a dev toolbox.
      <br><br>
      <code>Swift</code> <code>SwiftUI</code> <code>ScreenCaptureKit</code>
    </td>
    <td width="33%" valign="top">
      <h3><a href="https://github.com/MikeKiselyov/glass-home-android">Glass Home</a></h3>
      A calm, fast home screen for Android TV and Google TV: a clock over nature photos and a quiet row of apps, no ads. Comes with adb scripts that clean up a slow TV, all reversible.
      <br><br>
      <code>Kotlin</code> <code>Android TV</code> <code>adb</code>
    </td>
    <td width="33%" valign="top">
      <h3><a href="https://github.com/MikeKiselyov/bug-hunt">bug-hunt</a></h3>

      <br><br>
