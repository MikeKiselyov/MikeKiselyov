      <h3><a href="https://github.com/MikeKiselyov/bugbear-app">Bugbear</a></h3>
      A macOS menu bar app for QA. The last minutes of your screen are always kept, so the bug you just saw is already recorded. Screenshots and clips with arrows, steps and blur, the environment collected for you, and a dev toolbox.
      <br><br>
      <code>Swift</code> <code>SwiftUI</code> <code>ScreenCaptureKit</code>
    </td>

      <h3><a href="https://github.com/MikeKiselyov/bug-bounty">bug-bounty</a></h3>
      An open source playground for QA engineers: small realistic apps with planted bugs. Explore, mark a bug in two clicks and get it verified automatically.
      <br><br>
